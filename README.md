# FlareSimAE

An open-source lens flare effect for **Adobe After Effects**, based on
[FlareSim for Nuke](https://github.com/LocalStarlight/flaresim_nuke).

- **Windows:** CUDA (with CPU fallback)
- **macOS:** Metal (Apple Silicon / Intel)
- 1,370 built-in optical lens presets
- Manually position the light or detect bright sources

**[Download for Windows / Mac](https://github.com/ken-eizo/flaresim_ae/releases/latest)**

Unzip, copy the plug-in into your After Effects Plug-ins folder, then restart.
See [INSTALL.md](INSTALL.md) for details.

This project is not a "direct port" of filmsim_nuke; the author has incorporated original optimizations and features specifically for After Effects.
