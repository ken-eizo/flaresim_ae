# Installing FlareSimAE

Download the ZIP for your system from [Releases](https://github.com/ken-eizo/flaresim_ae/releases/latest). Close After Effects before installing.

## Windows

1. Extract the Windows ZIP.
2. Copy **`FlareLensAE.aex`** into:
   ```text
   C:\Program Files\Adobe\Adobe After Effects <version>\Support Files\Plug-ins\
   ```
3. Open After Effects and search for **FlareSimAE** in Effects & Presets.

## macOS

1. Extract the macOS ZIP.
2. Copy the entire **`FlareSimAE.plugin`** into:
   ```text
   /Applications/Adobe After Effects <version>/Plug-ins/
   ```
3. Open After Effects and search for **FlareSimAE**.

**Notes:** Remove older copies of the plug-in to avoid conflicts. The Mac bundle is ad-hoc signed and not notarized; if blocked, review the macOS security prompt and allow it only if you trust the source. Do not disable system security globally.

No separate lens files are required; all **1,370 presets** are already included.
